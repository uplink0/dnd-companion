# D&D Realm

Серверная основа игрового помощника D&D: чат с мастером, лист героя, партия, карта, задания, журнал, бестиарий, предметы и справочник используют одну PostgreSQL-базу и журнал игровых событий.

## Быстрый запуск

```bash
git clone https://github.com/uplink0/dnd-companion.git
cd dnd-companion
docker compose up --build
```

Сайт будет доступен на `http://localhost:3000`. При первом старте схема и демонстрационная кампания создаются автоматически. Данные сохраняются в Docker volume `dnd_data`.

Без Docker: скопируйте `.env.example` в `.env`, создайте PostgreSQL-базу, затем выполните `npm install`, `npm run db:init`, `npm start`.

## Игровая модель

- Кампания объединяет участников, сессии, героев, группу, локации, задания, журнал и сообщения.
- Значимые действия записываются в `game_events`; последствия транзакционно меняют состояние сущностей.
- Урон сначала расходует временные HP. При уроне концентрирующемуся герою создаётся проверка концентрации.
- Эффекты имеют источник, цель, тип, длительность и концентрацию. Новая концентрация прекращает прежнюю.
- Свойства предмета открываются независимо: известная сила не раскрывает скрытое свойство или проклятие.
- Бестиарий показывает только известные герою факты; детализация растёт от слуха до полного знания.
- Задания имеют статусы `AVAILABLE`, `ACTIVE`, `COMPLETED`, `DECLINED`, `FAILED` и отдельные цели.
- Персонаж начинает один; NPC можно пригласить, принять в группу или нанять.
- `LVL` — уровень D&D, `rank` — отдельный сюжетный ранг.

## API

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/api/bootstrap` | Данные первого экрана |
| POST | `/api/campaigns/:id/messages` | Действие игрока и ответ мастера |
| POST | `/api/campaigns/:id/rolls` | Бросок кубиков |
| POST | `/api/campaigns/:id/damage` | Урон и временные HP |
| POST | `/api/campaigns/:id/healing` | Лечение или временные HP |
| POST | `/api/campaigns/:id/effects` | Бафф, дебафф или состояние |
| POST | `/api/campaigns/:id/items/:entryId/identify` | Открытие свойства предмета |
| POST | `/api/campaigns/:id/quests/:questId/accept` | Принятие задания |
| POST | `/api/campaigns/:id/party/recruit` | Приглашение или найм союзника |
| GET | `/api/campaigns/:id/events` | Лента синхронизации |

## Развёртывание

На сервере установите Git и Docker, клонируйте репозиторий и выполните `docker compose up -d --build`. Перед публичным запуском замените пароль БД, вынесите секреты в `.env`, включите HTTPS в обратном прокси и добавьте авторизацию перед API.

Интерфейс находится в `public`, сервер — в `server`, схема и демоданные — в `db`, SVG-иконки — в `public/assets/icons`.
